# firmware/test — 호스트(PC) 검증

하드웨어 없이 PC에서 **수신 파이프라인의 로직·버퍼링**을 검사합니다. 태옥의 실제
AI export 코드에 우리 링버퍼/파이프라인을 붙여 컴파일·실행합니다.

## 실행

```bash
./build_and_run.sh
```

`feature_extract.c` / `inference.c`(태옥 코드)가 필요합니다. 스크립트가 아래 순서로 찾습니다:

1. 환경변수 `AI_EXPORT_DIR`
2. `firmware/X-CUBE-AI/` (통합 후 위치)
3. 저장소 루트 `ai/export/` (AI/Data가 main에 머지된 경우)

아직 머지 전이면 경로를 직접 지정해 실행하세요:

```bash
AI_EXPORT_DIR=/path/to/ai/export ./build_and_run.sh
```

## 무엇을 검증하나

- **[A] 기능 정확성** — 프레임이 순서대로 흐르고 32개마다 정확히 1윈도우 추론.
- **[B] 유실 카운터** — 버퍼가 넘칠 때 버려진 수를 정확히 계측(한 칸 비움 규칙 포함).
- **[C] 버퍼 유무 비교** — 같은 버스트에서 "ISR가 다 처리(=HW FIFO 3칸)" 대 "링버퍼 256칸"의 유실 차이.

> ⚠️ 정직 고지: 로직·버퍼링 검증입니다. 실제 500kbps 마이크로초 타이밍은 하드웨어에서 측정합니다.
